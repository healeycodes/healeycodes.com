Adding tiny details that I believe only I would notice while reading someone else's technical blog. Like making sure that a new keyword I'm hacking into TypeScript is syntax highlighted correctly in my post:

```ts
(function (Prism) {
	const tsWithDefer = Prism.languages.extend("typescript", {});
	tsWithDefer.keyword.unshift(/\bdefer\b/);

	Prism.languages["ts-with-defer"] = tsWithDefer;
})(Prism);
```

This was for [Adding Go's defer to the TypeScript Compiler](https://healeycodes.com/adding-defer-to-the-typescript-compiler).
